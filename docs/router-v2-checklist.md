# Router-v2: проверка на роутере

Чек-лист ручной проверки после установки router-v2. Выполняется на роутере
(OpenWrt) и на сервере панели. Сервер обновляется **первым**: старый сервер
не поймёт schema 2 и ответит `400`, новый совместим с агентом schema 1.

## 0. Порядок выката

- [ ] Обновить сервер и перезапустить его.
- [ ] Убедиться, что сервер отвечает: `GET /api/state`.
- [ ] Обновить агент на роутере (`router/bootstrap.sh` или `install.sh`).
- [ ] `/etc/config/homepanel` не потерял `server_url` и `secret`.

## 1. Базовое состояние

- [ ] `/etc/init.d/homepanel-agent status` — running.
- [ ] `/etc/init.d/homepanel-events status` — running.
- [ ] LuCI → *Services → Home Panel*: «Настроен» — да, ошибок нет.
- [ ] В статусе: «Наблюдатель событий» — работает, «nftables» — доступен.
- [ ] `ubus call homepanel status` возвращает `watcher`, `nft`,
      `last_control_error`.
- [ ] `GET /api/state` содержит блок `router` с `online: true`.

## 2. Мгновенные события

- [ ] Подключить телефон к WiFi и засечь время.
- [ ] Не позже **3 секунд** в панели появляется устройство/человек дома.
- [ ] Отключить WiFi на телефоне — уход появляется так же быстро.
- [ ] В логе watcher нет ошибок: `logread | grep homepanel-events`.

## 3. Проводные клиенты

- [ ] `bridge fdb show br-lan | grep -i <mac компьютера>` показывает MAC.
- [ ] `ip neigh show dev br-lan` показывает IP компьютера.
- [ ] В панели у компьютера бейдж «кабель», тип `wired`.
- [ ] Компьютер за микротиком-мостом виден (микротик прозрачен для L2).
- [ ] Если виден только MAC микротика — микротик делает NAT; проводные
      клиенты за ним панель не увидит (ожидаемое ограничение).

## 4. Трафик WiFi

- [ ] У WiFi-клиента в таблице устройств есть «за 5 мин: …» и спарклайн.
- [ ] Скачать файл на телефоне — значение растёт в течение пары минут.
- [ ] У проводного клиента трафик «—» (в v2 не собирается).

## 5. Пауза интернета

- [ ] В панели нажать «Пауза» у тестового клиента.
- [ ] На роутере: `nft list table inet homepanel` — table, set `paused`,
      chain `forward` и два правила drop.
- [ ] Клиент теряет интернет, но открывается LuCI роутера и работает DNS.
- [ ] «Вернуть» — интернет восстанавливается, set пуст.
- [ ] Перезагрузить роутер: после старта пауза снова активна (агент
      восстанавливает состояние с сервера).

## 6. Kick

- [ ] Нажать «Отключить» у WiFi-клиента.
- [ ] Клиент отключается от WiFi и переподключается (или остаётся вне сети).
- [ ] В `/api/state` → `commands` команда переходит в `done`.
- [ ] Через 60 секунд без подтверждения команда становится `error`
      (`timeout`).

## 7. Перезапуск агента

- [ ] Нажать «Перезапустить агент» в панели.
- [ ] Сервис поднимается, `status` обновляется, команда `done`.
- [ ] Панель не теряет данные, пока агент перезапускается.

## 8. Отказоустойчивость

- [ ] Остановить сервер — агент продолжает работать, в статусе ошибка
      отправки, после подъёма сервера отправка восстанавливается.
- [ ] Остановить watcher — агент продолжает слать снимки по интервалу 20 с.
- [ ] `reboot` роутера — оба сервиса поднимаются, паузы восстанавливаются.

## 9. Безопасность

- [ ] `curl -H 'X-Homepanel-Guest: <token>' -X POST .../api/control/kick`
      → `403`.
- [ ] Без гостевого заголовка POST работает (в v1 нет админ-аутентификации).
- [ ] Панель не опубликована в интернет без ограничения на прокси.

## 10. Регрессия v1

- [ ] Агент schema 1 (старая версия) по-прежнему даёт рабочий снимок:
      `sh router/tests/run.sh` на legacy-кейсе.
- [ ] Главная, история, аналитика и настройки открываются без ошибок.
- [ ] TV-режим и виджет `/api/widget.svg` работают.

## Откат

- [ ] Вернуть предыдущую версию агента: `sh /etc/homepanel/install.sh`
      из сохранённой копии, либо переустановить прошлый тег.
- [ ] Снять паузы: `nft delete table inet homepanel` на роутере.
- [ ] Сервер: остановить, вернуть файл БД из `backups/` или из экспорта.
